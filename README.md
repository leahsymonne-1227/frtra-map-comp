# Global Incident Footprint

A map component concept for a cybersecurity dashboard. It helps people see where security incidents originate, how many incidents are associated with each location, and explore more information about individual incidents.

Open 'https://leahsymonne-1227.github.io/frtra-map-comp/Global-Incident-Footprint-Demo-Light-and-Dark.html` in a browser to view the demo.
